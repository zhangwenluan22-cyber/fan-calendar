# fan-calendar

「烦烦日历」是一个手机优先的本地网页。每天只要点一下「烦」，浏览器会把这一次烦躁记录到当天，还能在月历里回看每天烦了多少次，并给每天写备注。

## 如何打开

在电脑上，直接双击 `standalone.html`，用浏览器打开即可。也可以右键选择用 Chrome、Safari、Edge 等浏览器打开。

## 如何在手机浏览器打开

把 `standalone.html` 发送到手机，或放到手机能访问的位置，例如网盘、本地文件、局域网共享目录。然后用手机浏览器打开这个 HTML 文件。

如果手机浏览器限制直接打开本地 HTML，可以在电脑上进入本项目目录，临时启动一个本地服务：

```bash
python3 -m http.server 8000
```

然后让手机和电脑连接同一个网络，用手机访问电脑的局域网地址加端口，例如 `http://你的电脑局域网地址:8000/standalone.html`。

## 添加到手机桌面

在 Safari 或 Chrome 中打开页面后，使用浏览器菜单里的「添加到主屏幕」或「添加到桌面」。不同手机和浏览器文案略有不同，通常在分享菜单或更多菜单里。

## 数据保存位置

所有烦躁次数、每日备注、震动开关、音效开关和音效类型都保存在当前浏览器的 `localStorage` 里。

这意味着：

- 不需要账号。
- 不需要后端。
- 不会接 API。
- 不会上传内容。
- 换浏览器、清理缓存、使用无痕模式，可能会看不到原来的数据。

## 导出和导入数据

页面底部有「数据管理」区域。

- 点击「导出数据」会下载一个 JSON 文件。
- 点击「导入数据」可以选择之前导出的 JSON 文件。
- 导入时会合并同日期数据，并覆盖同日期备注。

建议偶尔导出一次，免得浏览器清理数据后找不回来。

## 清空数据

点击「清空全部数据」会要求二次确认。确认后会清空所有已记录的次数和备注。清空后的数据只能通过之前导出的 JSON 文件恢复。
